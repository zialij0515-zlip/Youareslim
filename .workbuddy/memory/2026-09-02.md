## Phase B 预览问题修复：WXML 非法标签 + 云开发开关
- 用户按 `Ctrl+B` 编译报错：`./pages/data/data.wxml:1:272 expect end-tag 'text', near 'view'`。
- 根因：多个 wxml 页面混用了 HTML 标签 `<b>`、`<small>`，微信小程序 WXML 解析器不认识；且 `<text>` 内不能嵌套 `<view>` 等块级元素。
- 修复：将 `pages/data/data.wxml`、`pages/profile/profile.wxml`、`pages/poster/poster.wxml` 中的 `<b>` / `<small>` 全部替换为 `<text class="...">`，并用标准 WXML 结构重写。
- 云环境选择器未出现：根因是 `app.json` 缺少 `"cloud": true`，开发者工具未识别为云开发项目。已补上该字段。
- JS 语法校验无 HTML 标签残留，本地提交 2635472。
