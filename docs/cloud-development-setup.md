# 微信云开发接入说明

1. 在微信开发者工具打开本项目，点击“云开发”并创建环境。
2. 将环境 ID 填入 `utils/cloud.js` 的 `ENV_ID` 常量；不要提交生产密钥或管理员凭证。
3. 创建集合：`checkins`、`body_records`、`users`。发布前必须配置规则，确保普通用户只能读写自己的数据。
4. 图片上传使用 `wx.cloud.uploadFile`，保存前会先走本地记录，云环境配置后再同步；生产发布前应增加基于 openid 的云函数写入和失败重试队列。
5. 真机验收时验证：弱网重试、断网提示、上传失败、重复提交、跨用户数据隔离与存储文件权限。

当前仓库未配置任何云环境 ID，因此不能将本地验证结果视为真实云端联调通过。
